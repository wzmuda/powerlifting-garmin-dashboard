# Barbell Progress dashboard

Zwykla statyczna strona: `index.html`, `styles.css`, `app.js` i wygenerowany
`data/strength-progress.json`. Nie laczy sie z Garminem i nie zawiera tokenow,
ID aktywnosci ani surowych odpowiedzi API.

Lokalny podglad:

```bash
python -m http.server 8000 --directory dashboard
```
